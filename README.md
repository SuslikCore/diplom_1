В этом коде я написал Юнит-тесты для программы, которая помогает заказать бургер в Stellar Burgers. 
В коде я использовал моки, стабы и параметризацию

Изначальная заготовка кода [репозиторий](https://github.com/yandex-praktikum/QA-java-diplom-1) с заготовкой кода.

Подключены библиотеки: Jacoco, Mockito, JUnit 4.

Тестами были покрыты следующие классы `Bun`, `Burger`, `Ingredient`, `IngredientType`.
